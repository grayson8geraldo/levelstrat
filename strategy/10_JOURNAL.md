# 10 — ТОРГОВЫЙ ЖУРНАЛ

## Зачем вести журнал

Торговый журнал — это **единственный объективный инструмент** для оценки вашей торговли. Без журнала невозможно:
- Определить реальный винрейт
- Найти слабые места в стратегии
- Отследить эмоциональные паттерны
- Улучшить результаты системно

## Формулы ключевых метрик

### Винрейт (Win Rate)
```
Win Rate = (Количество прибыльных сделок / Общее количество сделок) × 100%

Ориентир: 45-55% для DLS стратегии (при R:R 2:1+ винрейт 45% = прибыль)
```

### Ожидание (Expectancy)
```
Expectancy = (Win Rate × Средний R прибыльных) - ((1 - Win Rate) × Средний R убыточных)

Пример:
  WR = 50%, Avg Win = 2.1R, Avg Loss = 1.0R
  Expectancy = (0.50 × 2.1) - (0.50 × 1.0) = 1.05 - 0.50 = 0.55R

  На каждую сделку вы ожидаете заработать 0.55R
  При риске $100 на сделку: ожидание = $55 на сделку
```

### Профит-фактор (Profit Factor)
```
Profit Factor = Сумма всех прибылей / Сумма всех убытков (абс.)

  > 2.0 = Отличная стратегия
  1.5 - 2.0 = Хорошая стратегия
  1.0 - 1.5 = Нужна оптимизация
  < 1.0 = Убыточная стратегия
```

### Максимальная просадка (Max Drawdown)
```
Max Drawdown = (Пиковый баланс - Минимальный баланс) / Пиковый баланс × 100%

Ориентир для DLS: Max Drawdown < 15%
Если > 20%: СТОП → Пересмотр стратегии → Демо
```

### Коэффициент Шарпа (упрощённый)
```
Sharpe Ratio = Средняя дневная доходность / Стандартное отклонение дневной доходности

  > 2.0 = Превосходная стратегия
  1.0 - 2.0 = Хорошая стратегия
  < 1.0 = Стратегия нуждается в улучшении
```

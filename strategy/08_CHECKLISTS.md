## Быстрый чек-лист (7 секунд)

Для опытных трейдеров — быстрая проверка перед нажатием кнопки:

```
Перед входом — 7 вопросов (ответ на каждый < 1 секунды):

  1. ТРЕНД?        → Да / Нет / Против
  2. УРОВЕНЬ?      → 3+ касаний / Наторгован / От экстремума
  3. ПОДТВЕРЖДЕНИЕ? → 3+ из 5
  4. СТОП?         → Установлен / Рассчитан
  5. РАЗМЕР?       → ≤ 1% риска
  6. ТЕЙКИ?        → TP1 / TP2 / TP3 размещены
  7. ФИЛЬТРЫ?      → P&L OK / Нет тилта / Позиций < 2

  Все "Да"? → ВХОД
  Хоть одно "Нет"? → СТОП. Пересмотр.
```

## Чек-лист по сценариям

### Сценарий 1: Нисходящий тренд (ШОРТ)

```
СПЕЦИФИЧЕСКИЕ ПРОВЕРКИ:
  [ ] EMA 9 < EMA 21 < EMA 50 на 15m
  [ ] Цена < EMA 200 на 1H
  [ ] RSI на 1H < 50 (медвежий контекст)
  [ ] Нисходящая наклонная сопротивления построена
  [ ] Каждый swing high НИЖЕ предыдущего
  [ ] Нет дивергенции RSI (бычьей) на 1H → если есть, НЕ ВХОДИТЬ
  [ ] OBV подтверждает нисходящий тренд
  [ ] Funding rate не экстремально отрицательный (> -0.1%)
```

### Сценарий 2: Восходящий тренд (ЛОНГ)

```
СПЕЦИФИЧЕСКИЕ ПРОВЕРКИ:
  [ ] EMA 9 > EMA 21 > EMA 50 на 15m
  [ ] Цена > EMA 200 на 1H
  [ ] RSI на 1H > 50 (бычий контекст)
  [ ] Восходящая наклонная поддержки построена
  [ ] Каждый swing low ВЫШЕ предыдущего
  [ ] Нет дивергенции RSI (медвежьей) на 1H → если есть, НЕ ВХОДИТЬ
  [ ] OBV подтверждает восходящий тренд
  [ ] Funding rate не экстремально положительный (< +0.1%)
```

### Сценарий 3: Памп (ШОРТ на сдутии)

```
СПЕЦИФИЧЕСКИЕ ПРОВЕРКИ:
  [ ] Памп > 10% за 1-4 часа подтверждён
  [ ] RSI был > 85 на пике (или < 15 для дампа)
  [ ] Минимум 2 FVG (имбалансные зоны) идентифицированы
  [ ] Сдутие началось (откат > 3% от вершины)
  [ ] RSI вернулся < 70
  [ ] Нисходящая наклонная по откатам сформирована (3+ касания)
  [ ] Размер позиции: 75% от стандарта
  [ ] Плечо: максимум 5x
  [ ] FVG зоны отмечены как цели (TP)
  [ ] OI начал снижаться (разгрузка позиций)
```

### Сценарий 4: Новый листинг

```
СПЕЦИФИЧЕСКИЕ ПРОВЕРКИ:
  [ ] Дата листинга: менее 60 дней назад
  [ ] Прошла минимум 1 неделя с листинга
  [ ] Объём 24ч стабильно > $20M
  [ ] Первичная структура (swing highs/lows) сформирована
  [ ] Наклонный уровень имеет 3+ касания
  [ ] Размер позиции: 75% от стандарта
  [ ] Плечо: максимум 5x
  [ ] R:R минимум 2.5:1 (повышенный порог)
  [ ] Временной стоп: 15 свечей (ускоренный)
  [ ] Нет предстоящих разблокировок токенов (token unlock)
```

  [ ] Обновить наклонные уровни на графиках
  [ ] Проверить текущий P&L (не превышен дневной/недельный лимит?)

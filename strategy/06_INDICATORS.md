# 06 — ИНДИКАТОРЫ И ИХ НАСТРОЙКИ

## Обзор индикаторной системы

Стратегия DLS использует **минималистичный, но мощный** набор индикаторов. Каждый индикатор выполняет конкретную роль и не дублирует другие.

```
╔══════════════════════════════════════════════════════════════════╗
║                ИНДИКАТОРНАЯ АРХИТЕКТУРА DLS                      ║
╠══════════════════════════════════════════════════════════════════╣
║                                                                  ║
║  ГРУППА 1: ТРЕНД                                               ║
║  ├── EMA 9 / 21 / 50       — Определение направления           ║
║  └── EMA 200                — Глобальный фильтр тренда         ║
║                                                                  ║
║  ГРУППА 2: МОМЕНТУМ                                            ║
║  ├── RSI (14)               — Перекупленность/перепроданность   ║
║  └── MACD (12, 26, 9)      — Импульс и дивергенции             ║
║                                                                  ║
║  ГРУППА 3: ОБЪЁМ                                                ║
║  ├── Volume                  — Базовый объём                    ║
║  ├── OBV                     — On-Balance Volume (поток денег)  ║
║  └── Volume Profile          — Распределение объёма по цене    ║
║                                                                  ║
║  ГРУППА 4: ВОЛАТИЛЬНОСТЬ                                       ║
║  ├── ATR (14)               — Средний истинный диапазон        ║
║  └── Bollinger Bands (20,2) — Каналы волатильности             ║
║                                                                  ║
║  ГРУППА 5: ДЕРИВАТИВЫ (внешние данные)                         ║
║  ├── Open Interest           — Открытый интерес                 ║
║  ├── Funding Rate            — Ставка финансирования            ║
║  └── Liquidation Map         — Карта ликвидаций                 ║
║                                                                  ║
╚══════════════════════════════════════════════════════════════════╝
```

## ГРУППА 1: ТРЕНД

### EMA (Exponential Moving Average)

**Настройки:**

| EMA | Период | Цвет (рекомендация) | Назначение |
|-----|--------|---------------------|------------|
| EMA 9 | 9 | Жёлтый | Быстрая — текущий моментум |
| EMA 21 | 21 | Оранжевый | Средняя — краткосрочный тренд |
| EMA 50 | 50 | Голубой | Медленная — среднесрочный тренд |
| EMA 200 | 200 | Белый/Красный | Глобальная — долгосрочный тренд |

**Применение в TradingView:**
```
Indicators → Built-in → Moving Average Exponential
Length: 9 (повторить для 21, 50, 200)
Source: Close
```

**Сигналы:**

```
БЫЧИЙ ВЕЕР (Bullish Fan) — ЛОНГ:

    EMA 9  ─────────── ↗ (сверху)
    EMA 21 ────────── ↗
    EMA 50 ─────────── ↗ (снизу)

    Порядок: EMA 9 > EMA 21 > EMA 50
    Все EMA направлены вверх
    Цена ВЫШЕ всех EMA


МЕДВЕЖИЙ ВЕЕР (Bearish Fan) — ШОРТ:

    EMA 50 ─────────── ↘ (сверху)
    EMA 21 ────────── ↘
    EMA 9  ─────────── ↘ (снизу)

    Порядок: EMA 9 < EMA 21 < EMA 50
    Все EMA направлены вниз
    Цена НИЖЕ всех EMA
```

**Дополнительные сигналы EMA:**

| Сигнал | Описание | Действие |
|--------|----------|----------|
| EMA 9 × EMA 21 вверх | Быстрая пересекает среднюю снизу вверх | Подтверждение лонга |
| EMA 9 × EMA 21 вниз | Быстрая пересекает среднюю сверху вниз | Подтверждение шорта |
| Цена > EMA 200 | Цена выше глобальной средней | Глобальный бычий контекст |
| Цена < EMA 200 | Цена ниже глобальной средней | Глобальный медвежий контекст |
| EMA компрессия | Все EMA сжались вместе | Готовится сильное движение |

### Совмещение EMA с наклонным уровнем

```
УСИЛЕННЫЙ СИГНАЛ: Наклонная поддержка совпадает с EMA 50

Цена:     ╲     /
           ╲   / ← Отбой
            ╲ /
             ● ← Касание наклонной
════════════/═══════════ Наклонная поддержка
     ~~~~~~~/~~~~~~~~~~~ EMA 50 (совпадает!)
           /
          /

→ Конфлюенция наклонной + EMA = усиленный лонг-сигнал
→ Увеличиваем позицию на 20%
```

## ГРУППА 2: МОМЕНТУМ

### RSI (Relative Strength Index)

**Настройки:**
```
Период: 14
Source: Close
Уровни: 30, 50, 70 (стандартные)
Дополнительные уровни: 20, 40, 60, 80 (для крипты)
```

**Применение в TradingView:**
```
Indicators → Built-in → Relative Strength Index
Length: 14
Source: Close
```

**Зоны RSI для DLS:**

```
RSI:

 100 ┃
     ┃
  80 ┃━━━━━━━━━━━━━━━━ ЭКСТРЕМАЛЬНАЯ перекупленность
     ┃                  → Только шорт (памп-сценарий)
  70 ┃━━━━━━━━━━━━━━━━ Перекупленность
     ┃                  → Готовимся к шорту от наклонной
  60 ┃━━━━━━━━━━━━━━━━ Бычья зона
     ┃                  → Лонги приоритетнее
  50 ┃━━━━━━━━━━━━━━━━ Нейтраль
     ┃
  40 ┃━━━━━━━━━━━━━━━━ Медвежья зона
     ┃                  → Шорты приоритетнее
  30 ┃━━━━━━━━━━━━━━━━ Перепроданность
     ┃                  → Готовимся к лонгу от наклонной
  20 ┃━━━━━━━━━━━━━━━━ ЭКСТРЕМАЛЬНАЯ перепроданность
     ┃                  → Только лонг (памп-сценарий на сдутии)
   0 ┃
```

**RSI дивергенции (самый сильный сигнал RSI):**

| Тип дивергенции | Цена | RSI | Сигнал | Сила |
|-----------------|------|-----|--------|------|
| Классическая бычья | Lower Low | Higher Low | ЛОНГ | ★★★★★ |
| Классическая медвежья | Higher High | Lower High | ШОРТ | ★★★★★ |
| Скрытая бычья | Higher Low | Lower Low | Продолжение ЛОНГ | ★★★★☆ |
| Скрытая медвежья | Lower High | Higher High | Продолжение ШОРТ | ★★★★☆ |

### MACD (Moving Average Convergence Divergence)

**Настройки:**
```
Fast Length: 12
Slow Length: 26
Signal Smoothing: 9
Source: Close
```

**Применение в TradingView:**
```
Indicators → Built-in → MACD
Fast: 12, Slow: 26, Signal: 9
```

**Сигналы MACD для DLS:**

| Сигнал | Условие | Действие |
|--------|---------|----------|
| Бычье пересечение | MACD линия пересекает Signal снизу вверх | Подтверждение ЛОНГ |
| Медвежье пересечение | MACD линия пересекает Signal сверху вниз | Подтверждение ШОРТ |
| Гистограмма растёт | Столбики увеличиваются (от нуля вверх) | Бычий моментум |
| Гистограмма падает | Столбики уменьшаются (от нуля вниз) | Медвежий моментум |
| Дивергенция | Цена и MACD расходятся | Сильнейший сигнал разворота |
| Zero Line Cross | MACD пересекает нулевую линию | Смена тренда |

## ГРУППА 3: ОБЪЁМ

### Volume (Базовый)

**Настройки:**
```
MA Length: 20 (скользящая средняя объёма)
```

**Правила объёма:**

```
Объём относительно MA(20):

  300%+ ┃ ████████████████████████  ЭКСТРЕМАЛЬНЫЙ
        ┃                            → Возможная манипуляция / кульминация
  200%  ┃ ████████████████████      ВЫСОКИЙ
        ┃                            → Подтверждение пробоя
  150%  ┃ ███████████████           ПОВЫШЕННЫЙ
        ┃                            → Подтверждение отбоя
  100%  ┃ ██████████                СРЕДНИЙ
        ┃                            → Базовый уровень (MA20)
   50%  ┃ █████                     НИЗКИЙ
        ┃                            → Слабый сигнал, не торгуем
   20%  ┃ ██                        СУХОЙ
        ┃                            → НЕ ВХОДИТЬ (нет ликвидности)
```

### OBV (On-Balance Volume)

**Настройки:**
```
Source: Close (стандартно)
```

**Применение:**

| OBV сигнал | Описание | Действие |
|------------|----------|----------|
| OBV растёт + цена растёт | Тренд подтверждён объёмом | Лонг подтверждён |
| OBV падает + цена падает | Тренд подтверждён объёмом | Шорт подтверждён |
| OBV растёт + цена падает | **Бычья дивергенция** | Готовимся к лонгу |
| OBV падает + цена растёт | **Медвежья дивергенция** | Готовимся к шорту |
| OBV пробил свой тренд | Смена потока капитала | Ранний сигнал разворота |

### Volume Profile

**Настройки:**
```
Тип: Fixed Range Volume Profile (FRVP)
Период: Последние 24 часа / Текущая сессия
Row Size: 50-100
```

**Ключевые уровни:**

| Уровень | Описание | Как использовать |
|---------|----------|------------------|
| **POC (Point of Control)** | Цена с максимальным объёмом | Магнит — цена стремится к POC |
| **VAH (Value Area High)** | Верхняя граница зоны стоимости | Сопротивление |
| **VAL (Value Area Low)** | Нижняя граница зоны стоимости | Поддержка |
| **HVN (High Volume Node)** | Зона высокого объёма | Цена замедляется здесь |
| **LVN (Low Volume Node)** | Зона низкого объёма | Цена пролетает быстро |

```
Совмещение Volume Profile с наклонным уровнем:

  Цена         Volume Profile
   │              ████
   │           ███████████
   │        ████████████████  ← HVN (зона торможения)
   │     ██████████████████████
═══╪════████████████████████████ ← Наклонная + POC = МОЩНАЯ зона
   │     ██████████████████████
   │        ██████████████
   │             ████████
   │                ████

   Конфлюенция: Наклонная + POC → Сильнейший вход
```

## ГРУППА 4: ВОЛАТИЛЬНОСТЬ

### ATR (Average True Range)

**Настройки:**
```
Период: 14
```

**Использование ATR в DLS:**

| Функция | Формула | Пример (ATR = $15 для ETH) |
|---------|---------|----------------------------|
| Стоп-лосс | Уровень ± 0.5 ATR | ±$7.50 |
| TP1 | Вход ± 1.5 ATR | ±$22.50 |
| TP2 | Вход ± 3.0 ATR | ±$45.00 |
| TP3 | Вход ± 4.5 ATR | ±$67.50 |
| Ширина зоны касания | ±0.15 ATR | ±$2.25 |
| Фильтр волатильности | ATR > 50% ATR(20) | Если ATR < $7.50 → не торгуем |

### Bollinger Bands

**Настройки:**
```
Length: 20
StdDev: 2.0
Source: Close
```

**Использование Bollinger Bands:**

```
Сжатие Bollinger Bands (Squeeze):

  Верхняя BB ──────╲    ╱──────
                    ╲  ╱
  SMA 20    ────────────────────
                    ╱  ╲
  Нижняя BB ──────╱    ╲──────

  СЖАТИЕ = Полосы сузились → готовится ВЗРЫВНОЕ движение
  → Ждём пробой наклонного уровня
  → Вход на пробой + расширение Bollinger Bands
```

| Сигнал BB | Описание | Действие |
|-----------|----------|----------|
| Цена у верхней BB + наклонное сопротивление | Двойное сопротивление | Усиленный шорт-сигнал |
| Цена у нижней BB + наклонная поддержка | Двойная поддержка | Усиленный лонг-сигнал |
| BB Squeeze + наклонный уровень | Сжатие у линии | Готовимся к пробою |
| Цена за BB (выход из канала) | Экстремальное отклонение | Возврат к среднему (Mean Reversion) |

## ГРУППА 5: ДЕРИВАТИВЫ (Внешние данные)

### Open Interest (OI)

**Источники:** Coinglass, CoinAnk, Bybit Analytics

| OI + Цена | Интерпретация | Действие |
|-----------|---------------|----------|
| OI ↑ + Цена ↑ | Новые лонги открываются | Тренд подтверждён, лонг |
| OI ↑ + Цена ↓ | Новые шорты открываются | Тренд подтверждён, шорт |
| OI ↓ + Цена ↑ | Шорты закрываются (Short Squeeze) | Осторожный лонг |
| OI ↓ + Цена ↓ | Лонги закрываются (Long Squeeze) | Осторожный шорт |
| OI резко ↑ (> 10% за час) | Перегрев — готовится ликвидация | Уменьшить позицию |
| OI резко ↓ (> 10% за час) | Массовые ликвидации уже прошли | Ищем разворот |

Подробная таблица — см. раздел 05 (Risk Management).

### Liquidation Map (Карта ликвидаций)

**Источники:** Hyblock Capital, Coinglass

```
Как использовать карту ликвидаций:

Цена
  │
  │    ░░░░░░░░░░░░  ← Кластер ликвидаций шортов
  │    ░░░░░░░░░░░░      Цена может "подтянуться" сюда
  │
  │ ●● Текущая цена
  │
  │    ████████████  ← Кластер ликвидаций лонгов
  │    ████████████      Цена может "упасть" сюда
  │

ПРАВИЛО: Цена как магнит тянется к кластерам ликвидаций.
         Не ставьте стоп в зоне кластера ликвидаций!
         Стоп должен быть ЗА кластером.
```

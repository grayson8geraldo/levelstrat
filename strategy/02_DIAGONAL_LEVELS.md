# 02 — ПОСТРОЕНИЕ НАКЛОННЫХ УРОВНЕЙ

## Определение

**Наклонный уровень (Diagonal Level)** — это динамическая линия поддержки или сопротивления, проведённая через 3 и более точек касания (экстремумов), отражающая скорость и направление ценового движения.

В отличие от горизонтальных уровней, наклонные содержат **временную компоненту** — они показывают не только ГДЕ цена реагирует, но и КОГДА следующая реакция произойдёт при продолжении движения с текущей скоростью.

---

## 4 Обязательных критерия валидного наклонного уровня

### Критерий 1: Вход по тренду (приоритет)

```
ПРИОРИТЕТ:
═══════════════════════════════════════════
 ★★★★★  По тренду           → Лучший вариант
 ★★★☆☆  Против тренда       → Допустимо, но с усиленными фильтрами
═══════════════════════════════════════════
```

**По тренду (предпочтительно):**
- Восходящий тренд → строим наклонную поддержку по минимумам → ЛОНГ от уровня
- Нисходящий тренд → строим наклонное сопротивление по максимумам → ШОРТ от уровня

**Против тренда (допустимо с ограничениями):**
- Восходящий тренд → строим наклонное сопротивление → ШОРТ от уровня
- Нисходящий тренд → строим наклонную поддержку → ЛОНГ от уровня
- **Требует:** дополнительное подтверждение дивергенцией, объёмом, FVG
- **Стоп** ставится плотнее (0.5 ATR вместо 1.0 ATR)
- **Размер позиции** уменьшается на 50%

### Критерий 2: 3 и более касания

```
Недостаточно (НЕ ТОРГУЕМ):

    ●
     \
      \
       ●                    ← Только 2 касания = линия без подтверждения
        \
         \


Достаточно (ТОРГУЕМ):

    ●
     \
      ●
       \
        ●                   ← 3 касания = валидный наклонный уровень
         \
          ● ← вход


Идеально (ПРИОРИТЕТ):

    ●
     \
      ●
       \
        ●
         \
          ●                 ← 4+ касания = сильный уровень, высокая вероятность
           \
            ● ← вход
```

**Правила подсчёта касаний:**

| Правило | Описание |
|---------|----------|
| **Тело или тень** | Считается касание как телом свечи, так и тенью |
| **Зона, не точка** | Допускается отклонение ±0.1-0.3% от линии (зона касания) |
| **Разнесённость** | Минимум 5 свечей между касаниями на рабочем ТФ |
| **Реакция** | Касание считается ТОЛЬКО если после него цена отскочила минимум на 0.3% |
| **Чистота** | Не должно быть пробитий тела свечи между касаниями |

### Критерий 3: Уровень должен быть наторгованным

**"Наторгованность"** означает, что вблизи наклонного уровня происходила **значительная торговая активность** — кластеры ордеров, повышенный объём, множественные реакции цены.

**Как определить наторгованность:**

```
Наторгованный уровень:                    Ненаторгованный уровень:

    │ ┃┃┃┃                                    │  │
    │┃┃┃┃┃┃                                   │  │
    │ ┃┃┃━━━━ 3 касание + объём               │  │━━━━ касание, но объём тонкий
    │┃┃┃┃┃                                    │  │
    │  ┃┃┃┃┃┃                                 │   │
    │   ┃┃┃━━━━ 2 касание + объём             │   │━━━━ касание без объёма
    │  ┃┃┃┃                                   │   │
    │   ┃┃┃┃┃┃┃                               │    │
    │    ┃┃┃━━━━ 1 касание + объём            │    │━━━━ касание без объёма
    │   ┃┃┃┃┃                                 │    │

    ✅ ТОРГУЕМ                                 ❌ НЕ ТОРГУЕМ
```

**Проверка наторгованности:**

1. **Volume Profile:** В зоне касаний объём выше среднего на 20%+
2. **Кластерный анализ:** Видны крупные сделки (кластеры покупок/продаж)
3. **Свечные паттерны:** В точках касания формируются разворотные свечи (пин-бары, доджи, поглощения)
4. **Время проторговки:** Цена задерживается у уровня на 3+ свечей (не просто пролетает)
5. **Footprint:** На footprint-графике видны крупные лимитные ордера вблизи уровня

### Критерий 4: Уровень построен от экстремума

**Экстремум** — это значимый максимум (swing high) или минимум (swing low), от которого начинается построение наклонного уровня.

```
Правильно — от экстремума:          Неправильно — от случайной точки:

    ★ ← Значимый максимум               │  │
   / \                                   │  │
  /   \                                  ●──────── случайная точка
 /     \   ★ ← Второй экстремум        / \
/       \ / \                           /   \
         ★   \   ★ ← Третий           /     \
              \ / \                   /       \
               ★   \                 /         \
                    ● ← ВХОД        /           \

✅ Наклонный уровень от экстремума    ❌ Произвольная линия
```

**Определение значимого экстремума:**

Для **swing high** (значимый максимум):
- Минимум 3 свечи слева и 3 свечи справа ниже данного максимума
- Локальный максимум должен быть виден на старшем таймфрейме (если строим на 15m — виден на 1H)
- Сформирован на повышенном объёме

Для **swing low** (значимый минимум):
- Минимум 3 свечи слева и 3 свечи справа выше данного минимума
- Локальный минимум должен быть виден на старшем таймфрейме
- Сформирован на повышенном объёме

## 4 Сценария построения наклонного уровня

### Сценарий A: Нисходящая наклонная сопротивления (Descending Resistance)

```
Направление торговли: ШОРТ (по тренду)

  ★ Экстремум (swing high)
   \
    \    ★ Касание 2
     \  / \
      \/   \   ★ Касание 3
       \  / \ / \
        \/   ●   \
         \       \
          \       ★ Касание 4  ← Точка входа в ШОРТ
           \     / \
            \   /   \
             \ /     \
              ▼       ▼ Продолжение падения

Наклонная линия: проводим через максимумы (swing highs)
Каждый следующий максимум НИЖЕ предыдущего
Угол наклона: 20°-60° относительно горизонтали
```

**Правила построения:**
1. Найти значимый swing high (экстремум) — начальная точка
2. Провести линию через следующий swing high (ниже первого)
3. Подтвердить третьим (и более) касанием
4. Убедиться в наторгованности каждой точки
5. Вход в шорт при следующем касании наклонной сверху

### Сценарий B: Восходящая наклонная поддержки (Ascending Support)

```
Направление торговли: ЛОНГ (по тренду)

                              ▲ Продолжение роста
                             /
                    ★       /
                   / \     /
          ★       /   \   /
         / \     /     \ /
★       /   \   /       ● Касание 4 ← Точка входа в ЛОНГ
 \     /     \ /       /
  \   /       ●       /
   \ /       /       /
    ●       /       /
   /       /       /
  ★ Экстремум (swing low)

Наклонная линия: проводим через минимумы (swing lows)
Каждый следующий минимум ВЫШЕ предыдущего
Угол наклона: 20°-60° относительно горизонтали
```

**Правила построения:**
1. Найти значимый swing low (экстремум) — начальная точка
2. Провести линию через следующий swing low (выше первого)
3. Подтвердить третьим (и более) касанием
4. Убедиться в наторгованности каждой точки
5. Вход в лонг при следующем касании наклонной снизу

### Сценарий C: Нисходящая наклонная поддержки (Descending Support — контр-тренд)

```
Направление торговли: ЛОНГ (против тренда — уменьшенная позиция!)

  Глобальный нисходящий тренд, но цена формирует нисходящий канал

  ══════ Наклонная сопротивления ══════
   \
    \   /\   /\
     \ /  \ /  \   /\
      ●    ●    \ /  \
     / \  / \    ●    \
    /   \/   \  / \    \
   /    /\    \/   \    \
  ═══════ Наклонная поддержки ═════════
       ★      ★      ★     ★ ← Вход в ЛОНГ от нижней наклонной

Лонг от нижней границы нисходящего канала
Цель: верхняя граница канала или 50% ширины канала
```

**Правила построения:**
1. Определить нисходящий канал (две параллельные наклонные)
2. Построить нижнюю наклонную через swing lows
3. 3+ касания нижней наклонной
4. Вход в лонг от нижней наклонной
5. **ВНИМАНИЕ:** Позиция 50% от стандартной, стоп плотнее

### Сценарий D: Восходящая наклонная сопротивления (Ascending Resistance — контр-тренд)

```
Направление торговли: ШОРТ (против тренда — уменьшенная позиция!)

  Глобальный восходящий тренд, но формируется восходящий канал

  ═══════ Наклонная сопротивления ═════════
        ★      ★      ★      ★ ← Вход в ШОРТ от верхней наклонной
   /    \     /\     /\     /
  /      \   /  \   /  \   /
 /        \ /    \ /    \ /
/          ●      ●      ●
\         / \    / \    / \
 \       /   \  /   \  /   \
  ═══════ Наклонная поддержки ═════════

Шорт от верхней границы восходящего канала
Цель: нижняя граница канала или 50% ширины канала
```

**Правила построения:**
1. Определить восходящий канал (две параллельные наклонные)
2. Построить верхнюю наклонную через swing highs
3. 3+ касания верхней наклонной
4. Вход в шорт от верхней наклонной
5. **ВНИМАНИЕ:** Позиция 50% от стандартной, стоп плотнее

## Правила построения наклонных уровней

### Угол наклона

| Угол | Оценка | Действие |
|------|--------|----------|
| < 15° | Слишком пологий | Ближе к горизонтальному уровню, не считаем наклонным |
| 15°–30° | Умеренный тренд | Хорошо для свинг-торговли, приемлемо для интрадей |
| 30°–50° | **Оптимальный** | **Лучший диапазон для интрадей торговли** |
| 50°–70° | Агрессивный тренд | Торгуем только по тренду, короткие стопы |
| > 70° | Параболический | Это памп — переходим к Сценарию Пампов (раздел 09) |

### Зона касания (Touch Zone)

Наклонный уровень — это не идеальная линия, а **зона**. Ширина зоны зависит от таймфрейма:

| Таймфрейм | Ширина зоны | Пример (для монеты $100) |
|-----------|-------------|--------------------------|
| 1m | ±0.05% | ±$0.05 |
| 5m | ±0.10% | ±$0.10 |
| 15m | ±0.15% | ±$0.15 |
| 1H | ±0.25% | ±$0.25 |
| 4H | ±0.40% | ±$0.40 |

### Деградация уровня

Наклонный уровень **теряет силу** со временем:

```
Сила уровня:

100% ┃━━━━━━━━━━━
     ┃           \
 80% ┃            \━━━━━━━━━
     ┃                      \
 60% ┃                       \━━━━━━━
     ┃                              \
 40% ┃                               \━━━━━
     ┃                                     \
 20% ┃                                      \━━━━━
     ┃
     ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
     Касание 3   Касание 4   Касание 5    Касание 6+

Пояснение: Каждое следующее касание ослабляет уровень.
После 5-го касания вероятность пробоя возрастает значительно.
```

**Правило деградации:**
- **Касание 3:** Полная сила — идеальный вход
- **Касание 4:** 80% силы — хороший вход
- **Касание 5:** 60% силы — вход с уменьшенной позицией (75%)
- **Касание 6+:** 40% силы — вероятен пробой, ищем пробойный вход вместо отбоя

### Пробой наклонного уровня

Пробой считается **подтверждённым** когда:

1. **Свеча закрылась** за уровнем (не просто проколола тенью)
2. **Закрытие произошло** на расстоянии > зоны касания от уровня
3. **Объём пробоя** выше среднего за последние 20 свечей
4. **Ретест** пробитого уровня (бывший support → resistance и наоборот) — лучший вход

```
Пробой наклонной поддержки с ретестом:

      /
     / ● Последнее касание (поддержка)
    /  │\
   /   │ \
  /    │  ╲ ПРОБОЙ ← закрытие ниже
 /     │   \
/══════╪════╲══════ Наклонная линия
       │     \  /
       │      \/
       │       ● РЕТЕСТ (бывшая поддержка теперь сопротивление)
       │      / \
       │     /   ↓ ВХОД В ШОРТ (по пробою с ретестом)
       │    /
       │   ▼
```

## Комбинация наклонных с горизонтальными уровнями

**Зоны конфлюенции** — точки где наклонный уровень пересекается с горизонтальным — дают **самые сильные сигналы**.

```
Конфлюенция (максимальная сила):

                    Горизонтальное сопротивление
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━●━━━━━━━━━━━━━━━━━
                              /│
                             / │
     Наклонная поддержка    /  │
                           /   │
══════════════════════════●════╪═══════════
                        /     │
                       /      │
                      /       │

        ТОЧКА КОНФЛЮЕНЦИИ = Пересечение наклонной и горизонтальной

        → Усиленный сигнал (увеличиваем позицию на 25%)
```

**Правило конфлюенции:** Если наклонный уровень совпадает с горизонтальным (отклонение ≤ 0.2%), сигнал считается усиленным:
- Вероятность отработки повышается
- Допускается увеличение позиции на 25%
- Стоп можно поставить плотнее (за обоими уровнями)

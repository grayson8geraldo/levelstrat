# 03 — ПРАВИЛА ВХОДА В СДЕЛКУ

## Система входа "Triple Confirmation" (Тройное подтверждение)

Вход в сделку разрешён ТОЛЬКО при наличии **минимум 3 из 5 подтверждений**:

```
╔═══════════════════════════════════════════════════════════════╗
║                    СИСТЕМА ПОДТВЕРЖДЕНИЙ                      ║
╠═══════════════════════════════════════════════════════════════╣
║                                                               ║
║  [1] НАКЛОННЫЙ УРОВЕНЬ  — Касание валидного уровня           ║
║  [2] СВЕЧНОЙ ПАТТЕРН    — Разворотная модель в зоне касания  ║
║  [3] ОБЪЁМ              — Объёмное подтверждение              ║
║  [4] ИНДИКАТОР          — RSI/MACD/OBV сигнал                ║
║  [5] КОНФЛЮЕНЦИЯ        — Совпадение с другим уровнем/зоной  ║
║                                                               ║
║  МИНИМУМ ДЛЯ ВХОДА:  3 из 5                                 ║
║  ИДЕАЛЬНЫЙ ВХОД:      5 из 5                                 ║
║                                                               ║
╚═══════════════════════════════════════════════════════════════╝
```

---

## Подтверждение 1: Наклонный уровень

Цена должна коснуться **валидного наклонного уровня** (см. раздел 02):

| Параметр | Для ЛОНГА | Для ШОРТА |
|----------|-----------|-----------|
| Тип уровня | Наклонная поддержка | Наклонная сопротивление |
| Минимум касаний | 3 (текущее = 4-е) | 3 (текущее = 4-е) |
| Зона входа | Нижняя граница зоны касания | Верхняя граница зоны касания |
| Наторгованность | Объём в зоне выше среднего | Объём в зоне выше среднего |
| Экстремум | Уровень начинается от swing low | Уровень начинается от swing high |

**Точка входа по наклонному уровню:**

```
ДЛЯ ЛОНГА (от наклонной поддержки):

         Зона касания
    ═══════╤══════════ верхняя граница
           │
    ───────┼────────── наклонная линия
           │
    ═══════╧══════════ нижняя граница ← ТОЧКА ВХОДА (limit order)
           │
     ------┼---------- стоп-лосс (за зоной)


ДЛЯ ШОРТА (от наклонного сопротивления):

     ------┼---------- стоп-лосс (за зоной)
           │
    ═══════╤══════════ верхняя граница ← ТОЧКА ВХОДА (limit order)
           │
    ───────┼────────── наклонная линия
           │
    ═══════╧══════════ нижняя граница
```

## Подтверждение 2: Свечной паттерн

В зоне касания наклонного уровня должен сформироваться **разворотный свечной паттерн**.

### Для ЛОНГА (бычьи паттерны):

| Паттерн | Сила | Описание |
|---------|------|----------|
| **Бычье поглощение** | ★★★★★ | Зелёная свеча полностью поглощает предыдущую красную |
| **Пин-бар (молот)** | ★★★★★ | Длинная нижняя тень (≥ 2x тело), маленькое тело вверху |
| **Утренняя звезда** | ★★★★☆ | Три свечи: красная + доджи/маленькая + зелёная |
| **Бычий харами** | ★★★☆☆ | Маленькая зелёная свеча внутри предыдущей красной |
| **Двойное дно (в миниатюре)** | ★★★★☆ | Две тени уперлись в наклонный уровень |

### Для ШОРТА (медвежьи паттерны):

| Паттерн | Сила | Описание |
|---------|------|----------|
| **Медвежье поглощение** | ★★★★★ | Красная свеча полностью поглощает предыдущую зелёную |
| **Падающая звезда** | ★★★★★ | Длинная верхняя тень (≥ 2x тело), маленькое тело внизу |
| **Вечерняя звезда** | ★★★★☆ | Три свечи: зелёная + доджи/маленькая + красная |
| **Медвежий харами** | ★★★☆☆ | Маленькая красная свеча внутри предыдущей зелёной |
| **Двойная вершина (в миниатюре)** | ★★★★☆ | Две тени уперлись в наклонное сопротивление |

### Свечной паттерн на рабочем ТФ (15m / 5m):

```
Пример: Бычье поглощение на наклонной поддержке

    │         ┃
    │    ┃    ┃
    │    ┃    ┃    ← Зелёная (бычья) свеча полностью
    │    ┃    ┃       поглощает предыдущую красную
    │    ┃    ┃
    │    ┃    ┃
    │         │
════╪═════════╪═══════ Наклонная поддержка
    │    │    │
    │    │

    [RED] [GREEN] ← ВХОД на закрытии зелёной свечи
```

## Подтверждение 3: Объём

### Для входа на ОТБОЙ от уровня:

```
Идеальная объёмная картина при отбое:

Цена:    ╲    /
          ╲  /
           ╲/ ← Касание наклонной

Объём:  ░░░░░░░░░░░░
        ░░░░░░░░░░░░░░
        ░░░░░░░░░░░░░░░░░░  ← Объём РАСТЁТ при подходе к уровню
        ░░░░░░░░░░░░░░░░░░░░░░
        ░░░░░░░░░░░░░░░░░░░░░░░░░░ ← ПИКОВЫЙ объём на касании
        ░░░░░░░░░░░░░░░░░░  ← Объём СНИЖАЕТСЯ при отбое
        ░░░░░░░░░░░░
```

**Правила объёма:**
1. **Объём на касании** > средний объём за 20 свечей минимум на 50%
2. **Объём отбоя** (первая свеча после касания) > средний объём
3. **Delta (разница покупок и продаж):** Положительная delta для лонга, отрицательная для шорта
4. Для лонга: объём покупок (BID) > объём продаж (ASK) в момент касания
5. Для шорта: объём продаж (ASK) > объём покупок (BID) в момент касания

### Для входа на ПРОБОЙ уровня:

```
Объём на пробое:

Цена:     │     /
          │    / ← Пробой вверх
══════════╪═══════════ Наклонное сопротивление
          │  /
          │ /
          │/

Объём:  ░░░░░░░░
        ░░░░░░░░░░░░
        ░░░░░░░░░░░░░░░░░░░░░░░░
        ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ ← ВЗРЫВНОЙ объём на пробое
        ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░
```

**Для пробоя:** Объём должен быть > 200% от среднего за 20 свечей.

## Подтверждение 4: Индикатор

### RSI (Relative Strength Index)

| Сделка | RSI условие | Описание |
|--------|-------------|----------|
| ЛОНГ от поддержки | RSI 25-40 | Перепроданность, разворот вверх |
| ШОРТ от сопротивления | RSI 60-75 | Перекупленность, разворот вниз |
| ЛОНГ пробой сопротивления | RSI > 50 и растёт | Моментум подтверждает пробой |
| ШОРТ пробой поддержки | RSI < 50 и падает | Моментум подтверждает пробой |

**Бонус: RSI дивергенция**

```
Скрытая бычья дивергенция на наклонной поддержке:

Цена:    ╲       ╲
          ╲       ╲      ← Цена: нижние минимумы (Higher Lows на наклонной)
           ╲       ╲

RSI:       ╱       ╱
          ╱       ╱      ← RSI: верхние минимумы (Lower Lows)
         ╱       ╱

= СИЛЬНЫЙ СИГНАЛ НА ЛОНГ
```

### MACD

| Сделка | MACD условие |
|--------|-------------|
| ЛОНГ | MACD линия пересекает сигнальную снизу вверх |
| ЛОНГ | Гистограмма переходит из отрицательной в положительную |
| ШОРТ | MACD линия пересекает сигнальную сверху вниз |
| ШОРТ | Гистограмма переходит из положительной в отрицательную |

### OBV (On-Balance Volume)

| Сделка | OBV условие |
|--------|-------------|
| ЛОНГ | OBV растёт при касании поддержки → покупатели сильнее |
| ШОРТ | OBV падает при касании сопротивления → продавцы сильнее |
| Пробой | OBV подтверждает направление пробоя (новый максимум/минимум OBV) |

## Подтверждение 5: Конфлюенция

**Дополнительные зоны, усиливающие наклонный уровень:**

| Конфлюенция | Бонус к силе | Описание |
|-------------|-------------|----------|
| **Горизонтальный уровень** | +30% | Наклонная совпадает с горизонтальным S/R |
| **EMA 50/100/200** | +20% | Наклонная совпадает со скользящей средней |
| **Уровень Фибоначчи** | +25% | Наклонная совпадает с уровнем 0.382/0.5/0.618 |
| **Имбалансная зона (FVG)** | +25% | Наклонная проходит через незаполненный FVG |
| **Зона ликвидаций** | +30% | Карта ликвидаций показывает кластер вблизи |
| **POC (Volume Profile)** | +20% | Point of Control совпадает с наклонной |
| **Круглый уровень** | +15% | Цена кратна $1000, $100, $10 и т.д. |

## Типы входа

### Тип 1: Агрессивный вход (Limit Order)

```
Когда: Уровень сильный (4+ касания), конфлюенция, по тренду
Как: Лимитный ордер на наклонном уровне
Стоп: За зоной касания
Преимущество: Лучшая цена входа
Риск: Цена может не дойти до ордера или пробить уровень
```

**Размещение:**
- ЛОНГ: Limit Buy на нижней границе зоны касания наклонной поддержки
- ШОРТ: Limit Sell на верхней границе зоны касания наклонного сопротивления

### Тип 2: Консервативный вход (Market на подтверждении)

```
Когда: Уровень стандартный (3 касания), без сильной конфлюенции
Как: Ждём свечной паттерн → входим рыночным ордером на закрытии свечи
Стоп: За зоной касания + за тенью свечного паттерна
Преимущество: Более надёжный — входим после подтверждения
Риск: Хуже цена входа (пропускаем часть движения)
```

**Размещение:**
- ЛОНГ: Market Buy на закрытии бычьей свечи (поглощение/пин-бар) от наклонной
- ШОРТ: Market Sell на закрытии медвежьей свечи от наклонной

### Тип 3: Пробойный вход (Stop Order)

```
Когда: Уровень ослаблен (5+ касаний) или контр-трендовый вход
Как: Стоп-ордер за уровнем, активируется при пробое
Стоп: За ретестом пробитого уровня
Преимущество: Торгуем пробой с подтверждением
Риск: Ложные пробои (особенно на крипте)
```

**Размещение:**
- ЛОНГ: Buy Stop выше наклонного сопротивления (пробой вверх)
- ШОРТ: Sell Stop ниже наклонной поддержки (пробой вниз)

### Тип 4: Вход на ретесте (лучший Risk/Reward)

```
Когда: Произошёл подтверждённый пробой наклонного уровня
Как: Ждём возврат цены к пробитому уровню (ретест), входим от него
Стоп: За уровнем (с другой стороны от пробоя)
Преимущество: Лучший R:R, подтверждённый пробой
Риск: Цена может не вернуться на ретест (пропускаем сделку)
```

**Размещение:**
- ЛОНГ: Limit Buy на пробитом наклонном сопротивлении (теперь поддержка)
- ШОРТ: Limit Sell на пробитой наклонной поддержке (теперь сопротивление)

---

## Размер позиции в зависимости от типа входа

| Тип входа | Размер позиции | R:R минимум |
|-----------|---------------|-------------|
| Агрессивный (limit) | 100% стандартной | 2.5:1 |
| Консервативный (market) | 100% стандартной | 2:1 |
| Пробойный (stop) | 75% стандартной | 3:1 |
| Ретест | 100% стандартной | 3:1 |
| Контр-тренд (любой тип) | 50% стандартной | 3:1 |

## Запрет входа (No-Trade Zones)

**НЕ входить в сделку если:**

1. Менее 3 подтверждений из 5
2. Наклонный уровень имеет менее 3 касаний
3. Объём ниже среднего (тонкий рынок)
4. Через 30 минут выходят ключевые макро-данные
5. Funding rate экстремален (> 0.1% или < -0.1%) — рынок перегрет
6. Уже есть 2 открытые позиции (максимум одновременных сделок = 2)
7. Серия из 3+ убыточных сделок подряд (пауза минимум 1 час)
8. Спред > 0.1% (низкая ликвидность)
9. Open Interest упал > 10% за последний час (массовые закрытия)
10. Свеча пробила уровень, но закрылась обратно (ложный пробой — ждём ретест)

# 04 — ПРАВИЛА ВЫХОДА ИЗ СДЕЛКИ

## Философия выхода

> "Вход определяет риск, выход определяет прибыль."

Система выхода DLS использует **трёхуровневую фиксацию прибыли** с **динамическим трейлинг-стопом** вдоль наклонного уровня.

---

## Стоп-лосс (Stop Loss)

### Размещение стопа

```
ДЛЯ ЛОНГА:

    ═══════════════════ Наклонная поддержка
          │
    ──────┼──────────── Нижняя граница зоны касания
          │
    ═══╤══╧══════════ СТОП-ЛОСС
       │
       │← Буфер = 0.5 × ATR(14) на рабочем ТФ
       │


ДЛЯ ШОРТА:

       │← Буфер = 0.5 × ATR(14) на рабочем ТФ
       │
    ═══╧══╤══════════ СТОП-ЛОСС
          │
    ──────┼──────────── Верхняя граница зоны касания
          │
    ═══════════════════ Наклонное сопротивление
```

### Формула стоп-лосса

```
ЛОНГ:
  Stop Loss = Наклонная поддержка - Ширина зоны - (0.5 × ATR14)

ШОРТ:
  Stop Loss = Наклонное сопротивление + Ширина зоны + (0.5 × ATR14)
```

### Типы стоп-лоссов

| Тип | Когда | Размер |
|-----|-------|--------|
| **Жёсткий (Hard Stop)** | Всегда | За зоной + 0.5 ATR |
| **Временной (Time Stop)** | Цена не двигается | Закрытие через 20 свечей рабочего ТФ |
| **Структурный** | Пробой структуры | Закрытие за ближайшим swing high/low |

### Временной стоп (Time Stop)

Если после входа **цена не пошла в нужном направлении в течение 20 свечей** рабочего таймфрейма — закрываем позицию по рынку, вне зависимости от P&L.

```
Пример (рабочий ТФ = 15m):
  20 свечей × 15 минут = 5 часов

Если через 5 часов цена в боковике → ЗАКРЫВАЕМ
```

Логика: Если уровень сработал, цена должна показать реакцию быстро. Отсутствие движения = ослабление сетапа.

## Тейк-профит (Take Profit)

### Трёхуровневая фиксация

```
╔════════════════════════════════════════════════════════════╗
║              СИСТЕМА ТЕЙК-ПРОФИТОВ                        ║
╠════════════════════════════════════════════════════════════╣
║                                                            ║
║  TP1 (30% позиции):  1.0 × Расстояние до стопа (1:1)    ║
║  TP2 (40% позиции):  2.0 × Расстояние до стопа (2:1)    ║
║  TP3 (30% позиции):  3.0 × Расстояние до стопа (3:1)    ║
║                                                            ║
║  Средний R:R = (0.3×1 + 0.4×2 + 0.3×3) / 1 = 2.0:1     ║
║                                                            ║
╚════════════════════════════════════════════════════════════╝
```

### Визуализация (ЛОНГ):

```
Цена
  ↑
  │
  │  ═══════════════ TP3 (3R) → Закрываем оставшиеся 30%
  │
  │  ═══════════════ TP2 (2R) → Закрываем 40%, стоп → TP1
  │
  │  ═══════════════ TP1 (1R) → Закрываем 30%, стоп → безубыток
  │
  │  ●●●●●●●●●●●●●● ВХОД
  │
  │  ═══════════════ СТОП-ЛОСС (1R)
  │
```

### Визуализация (ШОРТ):

```
Цена
  ↑
  │
  │  ═══════════════ СТОП-ЛОСС (1R)
  │
  │  ●●●●●●●●●●●●●● ВХОД
  │
  │  ═══════════════ TP1 (1R) → Закрываем 30%, стоп → безубыток
  │
  │  ═══════════════ TP2 (2R) → Закрываем 40%, стоп → TP1
  │
  │  ═══════════════ TP3 (3R) → Закрываем оставшиеся 30%
  │
```

### Определение целей тейк-профита

**Метод 1: По R-множителю (основной)**
- TP1 = 1R от входа
- TP2 = 2R от входа
- TP3 = 3R от входа

**Метод 2: По структуре (дополнительный)**
- TP1 = Ближайший горизонтальный уровень
- TP2 = Следующий структурный уровень или противоположная граница канала
- TP3 = Следующий значимый swing high/low

**Метод 3: По наклонному каналу (для сценариев C и D)**
- TP1 = 50% ширины канала
- TP2 = Противоположная наклонная канала
- TP3 = 120% ширины канала (за каналом)

**Правило:** Используйте **более консервативную** цель из двух методов. Если структурный уровень ближе, чем R-множитель — используйте структурный.

## Динамический трейлинг-стоп вдоль наклонного уровня

### Концепция

После достижения TP1 стоп-лосс перемещается **вдоль наклонного уровня**, следуя за трендом:

```
ЛОНГ (трейлинг вдоль восходящей наклонной):

Цена:           /
               /  ← TP2
              /
             /  ← TP1 достигнут!
            /
═══════════/═══════════════════ Начальный стоп
          /
         / ● ВХОД
        /
═══════/═══════ Наклонная поддержка

  Время ──────────────────────────────►

  После TP1:
    Стоп перемещается на уровень входа (безубыток)

  После TP2:
    Стоп перемещается на уровень TP1

  Параллельно:
    Стоп "скользит" вдоль наклонной поддержки
    (учитывая угол наклона и временную компоненту)
```

### Формула трейлинг-стопа

```
Для ЛОНГА:
  Trailing Stop = Текущая_точка_наклонной - (0.3 × ATR14)

  Где:
    Текущая_точка_наклонной = Начало_линии + (Угол_наклона × Количество_свечей)

Для ШОРТА:
  Trailing Stop = Текущая_точка_наклонной + (0.3 × ATR14)
```

### Правила перемещения стопа

| Событие | Действие со стопом |
|---------|-------------------|
| Вход совершён | Стоп = За зоной касания + 0.5 ATR |
| TP1 достигнут | Стоп → Цена входа (безубыток) |
| TP2 достигнут | Стоп → Уровень TP1 |
| Каждые 5 свечей | Стоп подтягивается вдоль наклонной |
| Появилась дивергенция | Закрываем 50% оставшейся позиции |
| Объём резко упал | Подтягиваем стоп плотнее (0.2 ATR) |

## Экстренный выход

### Ситуации для немедленного закрытия позиции:

1. **Пробой наклонного уровня** — свеча закрылась за стопом
2. **Аномальный объём** — объём > 500% от среднего (возможная манипуляция)
3. **Flash crash / Flash pump** — движение > 5% за 1 минуту
4. **Технические проблемы** — зависание биржи, проблемы с интернетом
5. **Чёрный лебедь** — экстренные новости (хак биржи, регуляторные новости)
6. **Funding rate переворот** — резкая смена с положительного на отрицательный (или наоборот)

### Правило экстренного выхода

```
⚠️ При ЛЮБОЙ из ситуаций выше:
   → Закрываем 100% позиции РЫНОЧНЫМ ОРДЕРОМ
   → Не ждём тейк-профит
   → Не пытаемся "пересидеть"
   → Фиксируем убыток и анализируем позже
```

## Матрица выхода по сценариям

### Сценарий A (Шорт по нисходящей наклонной)

| Параметр | Значение |
|----------|----------|
| Стоп | Выше наклонного сопротивления + 0.5 ATR |
| TP1 | 1R вниз или ближайшая поддержка |
| TP2 | 2R вниз или следующая поддержка |
| TP3 | 3R вниз или значимый swing low |
| Трейлинг | Вдоль нисходящей наклонной (стоп скользит вниз) |

### Сценарий B (Лонг по восходящей наклонной)

| Параметр | Значение |
|----------|----------|
| Стоп | Ниже наклонной поддержки + 0.5 ATR |
| TP1 | 1R вверх или ближайшее сопротивление |
| TP2 | 2R вверх или следующее сопротивление |
| TP3 | 3R вверх или значимый swing high |
| Трейлинг | Вдоль восходящей наклонной (стоп скользит вверх) |

### Сценарий C (Лонг контр-тренд от нижней наклонной канала)

| Параметр | Значение |
|----------|----------|
| Стоп | Ниже нижней наклонной + 0.3 ATR (плотнее!) |
| TP1 | 50% ширины канала |
| TP2 | Верхняя наклонная канала |
| TP3 | Нет (закрываем 100% на TP2) |
| Трейлинг | Агрессивный — подтягиваем каждые 3 свечи |

### Сценарий D (Шорт контр-тренд от верхней наклонной канала)

| Параметр | Значение |
|----------|----------|
| Стоп | Выше верхней наклонной + 0.3 ATR (плотнее!) |
| TP1 | 50% ширины канала |
| TP2 | Нижняя наклонная канала |
| TP3 | Нет (закрываем 100% на TP2) |
| Трейлинг | Агрессивный — подтягиваем каждые 3 свечи |

## Часть позиции vs полная позиция

### Шкала закрытия

```
Сигнал слабеет:
  Закрыть 25-50% позиции, подтянуть стоп

Сигнал разворачивается:
  Закрыть 75% позиции, стоп на безубыток

Полный разворот:
  Закрыть 100% позиции рыночным ордером

Стоп сработал:
  Позиция закрывается автоматически
```

### Признаки ослабления сигнала

1. RSI дивергенция против позиции
2. Объём снижается при движении в нашу сторону
3. Формируются свечи неопределённости (доджи, волчки)
4. OBV разворачивается против позиции
5. Цена замедляется перед тейк-профитом (консолидация)

# 09 — ТОРГОВЛЯ ПАМПОВ: ВХОД НА СДУТИИ

## Философия торговли пампов

> "Не пытайся поймать ракету — ищи обломки после взлёта."

Торговля пампов в стратегии DLS — это **не попытка поймать движение вверх**, а **осознанная торговля коррекции** после экстремального импульса. Мы используем имбалансные зоны (FVG) и наклонные уровни для точного входа на сдутии.

---

## Определение пампа

### Количественные критерии

| Параметр | Минимальное значение | Комментарий |
|----------|---------------------|-------------|
| Движение цены | > 10% за 1-4 часа | Резкий однонаправленный импульс |
| Объём | > 300% от среднего 24ч | Экстремальный всплеск активности |
| Зелёные свечи (лонг) / Красные (шорт) | 5+ подряд без коррекции | Однонаправленный поток ордеров |
| RSI (15m) | > 85 (бычий) / < 15 (медвежий) | Экстремальная перекупленность/перепроданность |
| Open Interest | Рост > 15% за время импульса | Новые позиции открываются |
| FVG (имбалансы) | Минимум 2 зоны | Цена пролетела без торгов |

### Типы пампов

```
ТИП 1: Новостной памп
  Причина: Листинг на крупной бирже, партнёрство, апдейт
  Характер: Быстрый V-образный импульс
  Сдутие: 30-60% от движения
  Длительность: 1-6 часов
  Торгуемость: ★★★★★ (отличная)

ТИП 2: Ликвидационный каскад
  Причина: Массовые ликвидации шортистов/лонгистов
  Характер: Ступенчатый импульс с ускорением
  Сдутие: 40-70% от движения
  Длительность: 30 минут - 2 часа
  Торгуемость: ★★★★☆ (хорошая)

ТИП 3: Китовая манипуляция
  Причина: Крупный игрок двигает цену
  Характер: Резкий шпиль (spike) с мгновенным возвратом
  Сдутие: 70-100% от движения
  Длительность: 5-30 минут
  Торгуемость: ★★★☆☆ (рискованная, быстрая)

ТИП 4: Органический рост
  Причина: Реальный спрос, тренд
  Характер: Постепенное ускорение с паузами
  Сдутие: 20-40% от движения
  Длительность: 6-24 часа
  Торгуемость: ★★★★☆ (хорошая, но глубокого сдутия не будет)
```

## Фаза 1: Идентификация и наблюдение

### Как обнаружить памп в реальном времени

```
ИНСТРУМЕНТЫ МОНИТОРИНГА:

1. TradingView Screener:
   - Фильтр: Change% (5m) > 3% И Volume > 300% от среднего
   - Фильтр: RSI(14) > 80 НА 15m

2. Coinglass / CoinAnk:
   - Liquidation Map: Каскад ликвидаций в одном направлении
   - OI Change: Резкий рост > 10%

3. Aggr.trade:
   - Лента сделок: Серия крупных маркет-ордеров (> $100K)

4. Ручной мониторинг:
   - Watchlist из 20-30 монет с объёмом > $20M
   - Алерты на TradingView: RSI > 80, RSI < 20, Volume > 300% MA
```

## Фаза 2: Картирование имбалансных зон (FVG)

### Как найти и разметить FVG

```
ПРИМЕР РАЗМЕТКИ ПАМПА (движение с $100 до $130):

  $130 │ ╱╲ ← ВЕРШИНА
       │╱  ╲

       │     ╲

  $124 │════════╲════
       │         ╲
  $122 │          ╲
       │           ╲
  $120 │════════════╲ FVG #2: $118 - $120 (второй, средний)
       │             ╲
  $118 │══════════════╲
       │               ╲
  $116 │                ╲
       │                 ╲
  $114 │══════════════════╲ FVG #3: $112 - $114 (третий, глубокий)
       │                   ╲
  $112 │════════════════════╲
       │                     ╲
  $110 │                      ╲
       │                       ╲
  $108 │                        ╲
       │                         ╲
  $106 │                          ╲
       │                           ╲
  $104 │                            ╲
       │                             ╲
  $102 │                              ╲
       │                               ╲
  $100 │────────────────────────────────  Цена ДО пампа
```

### Приоритет FVG зон

| Приоритет | FVG зона | Вероятность заполнения | Действие |
|-----------|----------|----------------------|----------|
| **1 (Высший)** | FVG #1 (ближе к вершине) | 80-90% | Первая цель для шорта |
| **2 (Средний)** | FVG #2 (средняя) | 60-75% | Вторая цель / зона входа в лонг |
| **3 (Глубокий)** | FVG #3 (ближе к началу) | 40-60% | Агрессивная цель / глубокий лонг |

### Правила валидности FVG

```
FVG ВАЛИДЕН если:
  ✓ Образован минимум 3 свечами (стандартная модель)
  ✓ Размер FVG > 0.3% от цены актива
  ✓ Объём свечи-импульса (средней) > 200% от среднего
  ✓ Зона не была "заполнена" (цена не возвращалась)
  ✓ Возраст FVG < 48 часов (для интрадей)

FVG НЕВАЛИДЕН если:
  ✗ Цена уже вернулась и прошла через зону
  ✗ Размер FVG < 0.1% (слишком маленький)
  ✗ Прошло > 48 часов без возврата к зоне
```

## Фаза 3: Ожидание сдутия

### Сигналы начала сдутия

```
СДУТИЕ НАЧИНАЕТСЯ когда (минимум 3 из 5):

  [ ] Первая красная свеча (для бычьего пампа) закрылась > 1% вниз
  [ ] RSI опустился ниже 70 (был > 85)
  [ ] Объём снизился > 50% от пикового
  [ ] Появились тени вверху свечей (selling pressure)
  [ ] OI начал снижаться (позиции закрываются)
```

### Что делать во время ожидания

```
  ⏳ ЖДЁМ и НАБЛЮДАЕМ:

  1. НЕ входим на вершине пампа
  2. Размечаем FVG зоны
  3. Начинаем строить наклонную по первым swing highs коррекции
  4. Мониторим объём (должен снижаться)
  5. Ждём формирования 3 точек для наклонной

  ⚠️ ТЕРПЕНИЕ — ключевой навык в торговле пампов!
```

## Фаза 4: Построение наклонной и вход

### Метод 1: ШОРТ от наклонной на сдутии

```
Построение нисходящей наклонной по swing highs коррекции:

  $130 ★ Вершина пампа (Экстремум #1)
        \
  $128   \
          \
  $126     ★ Swing High #2 (первый отскок)
            \
  $124       \
              \
  $122         ★ Swing High #3 (второй отскок) → 3 касания!
                \
  $121           \★ Касание #4 → ВХОД В ШОРТ
                  \
  $120 ════════════\══════ FVG #2 ← TP1
                    \
  $118 ══════════════\════
                      \
  $116                 \
                        \
  $114 ══════════════════\══ FVG #3 ← TP2
                          \
  $112 ════════════════════\═
                            \
  $110                       ▼ TP3 (цена до пампа)
```

**Параметры входа:**
```
  Вход: Шорт $121 (от наклонной сопротивления на сдутии)
  Стоп: $123 (за наклонной + буфер)
  Риск: $2 (1.65%)

  TP1 (30%): $119 (R:R = 1:1) — верхняя граница FVG #2
  TP2 (40%): $115 (R:R = 3:1) — внутри FVG #3
  TP3 (30%): $110 (R:R = 5.5:1) — цена до пампа

  Размер позиции: 75% от стандарта (памп = повышенный риск)
  Плечо: 3x-5x
```

### Метод 2: ЛОНГ от FVG зоны (заполнение имбаланса)

```
Когда применять:
  - Памп был ОРГАНИЧЕСКИМ (реальный спрос, новости)
  - Есть фундаментальные причины для продолжения роста
  - Цена дошла до глубокого FVG и показала реакцию

  $130 │ ╱╲ Вершина
       │╱  ╲
  $125 │    ╲
       │     ╲
  $120 │══════╲══════ FVG #2
       │       ╲
  $118 │════════● ← ВХОД В ЛОНГ (реакция от FVG)
       │       / \
  $116 │      /   ╲
       │     /     ╲
  $114 │    /       ╲
       │   /         ╲
  $112 │══/═══════════╲ FVG #3 ← СТОП ниже этой зоны
       │ /
  $110 │/

  Вход: Лонг $118 (от нижней границы FVG #2)
  Стоп: $111 (ниже FVG #3)
  TP1: $122
  TP2: $126
  TP3: $130 (ретест вершины)
```

## Фаза 5: Управление позицией при торговле пампа

### Специальные правила для пампов

```
⚠️ ПАМПЫ БОЛЕЕ ВОЛАТИЛЬНЫ — УЖЕСТОЧАЕМ ПРАВИЛА:

  1. Максимальное плечо: 5x (даже если обычно торгуете 10x)
  2. Размер позиции: 75% от стандартного
  3. Трейлинг-стоп: каждые 3 свечи (не 5)
  4. Временной стоп: 10 свечей (не 20)
  5. При росте OI > 5% за час → подтягиваем стоп на 50%
  6. При развороте RSI в противоположную сторону → закрываем 50%
  7. Если Funding Rate переворачивается → закрываем 100%
```

### Сценарий продолжения пампа (Trap)

```
⚠️ ЛОВУШКА: Памп может возобновиться!

Если после входа в ШОРТ:
  - Цена пробила наклонную вверх
  - Объём вырос до новых максимумов
  - OI снова растёт

→ НЕМЕДЛЕННЫЙ ВЫХОД по стопу!
→ НЕ переворачиваться в лонг (подождать новый сетап)
→ Пауза минимум 30 минут
```

## Примеры: Когда НЕ торговать памп

```
❌ НЕ ТОРГУЕМ если:

1. Движение < 10% → Это обычный тренд, не памп
2. Объём < 200% от среднего → Недостаточно импульса
3. Нет FVG (имбалансов) → Движение было постепенным
4. Прошло > 24 часа с пампа → Зоны "остыли"
5. Монета с объёмом < $20M → Ликвидность недостаточна
6. Стоп получается > 3% → Слишком далеко, невыгодный R:R
7. Это токен из категории "мемкоин" с капитализацией < $50M → манипуляция
8. Open Interest не изменился → Памп на спотовом рынке, не на фьючерсах
```

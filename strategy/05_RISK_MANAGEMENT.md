## Расчёт размера позиции

### Формула

```
                     Депозит × Риск_на_сделку(%)
Размер позиции ($) = ─────────────────────────────
                     Расстояние_до_стопа(%)

Количество монет = Размер_позиции / Цена_входа
```

### Пример расчёта

```
Исходные данные:
  Депозит:              $10,000
  Риск на сделку:       1% = $100
  Цена входа (ЛОНГ):   $2,500 (ETH)
  Наклонная поддержка:  $2,490
  Зона касания:         ±$3.75 (0.15% для 15m)
  ATR(14) на 15m:       $15
  Стоп-лосс:           $2,490 - $3.75 - ($15 × 0.5) = $2,478.75

Расчёт:
  Расстояние до стопа:  $2,500 - $2,478.75 = $21.25
  Расстояние в %:       21.25 / 2500 = 0.85%

  Размер позиции:       $100 / 0.0085 = $11,765
  При плече 5x:         Маржа = $11,765 / 5 = $2,353

  Количество ETH:       11,765 / 2,500 = 4.706 ETH

Проверка:
  Убыток при стопе:     4.706 × $21.25 = $100 ✓ (ровно 1% от депозита)

Тейки:
  TP1 (1R):  $2,500 + $21.25 = $2,521.25  → +$100 на 30% позиции
  TP2 (2R):  $2,500 + $42.50 = $2,542.50  → +$200 на 40% позиции
  TP3 (3R):  $2,500 + $63.75 = $2,563.75  → +$300 на 30% позиции
```

## Система управления рисками

### Уровень 1: Риск на сделку

| Параметр | Стандарт | Агрессивный | Консервативный |
|----------|----------|-------------|----------------|
| Риск на сделку | 1.0% | 1.5% | 0.5% |
| Макс. одновременных | 2 | 3 | 1 |
| Макс. плечо | 5x | 10x | 3x |
| Макс. совокупный риск | 2.0% | 3.0% | 0.5% |

### Уровень 2: Дневной лимит

```
Дневной P&L трекер:

 +3% ┃                         ← Цель дня (после достижения → стоп торговли)
     ┃
 +2% ┃
     ┃
 +1% ┃
     ┃
  0% ┃━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ Начало дня
     ┃
 -1% ┃                         ← Предупреждение (уменьшить размер на 50%)
     ┃
 -2% ┃                         ← Критический уровень (только 1 сделка за раз)
     ┃
 -3% ┃                         ← СТОП ТОРГОВЛИ НА ДЕНЬ
     ┃
```

**Правила:**
- При P&L = -1%: Уменьшить размер позиции на 50%
- При P&L = -2%: Максимум 1 открытая позиция, размер 50%
- При P&L = -3%: **ПРЕКРАТИТЬ ТОРГОВЛЮ НА ДЕНЬ**
- При P&L = +3%: Зафиксировать прибыль, прекратить торговлю

### Уровень 3: Недельный лимит

| Ситуация | Действие |
|----------|----------|
| Убыток за неделю = -3% | Уменьшить размер позиции на 50% до конца недели |
| Убыток за неделю = -5% | **ПРЕКРАТИТЬ ТОРГОВЛЮ ДО ПОНЕДЕЛЬНИКА** |
| Прибыль за неделю = +10% | Уменьшить размер на 25% (защита прибыли) |

### Уровень 4: Месячный просадка

```
Просадка от максимума:

  0%  ┃ Нормальная торговля
      ┃
 -5%  ┃ Уменьшить риск на сделку до 0.75%
      ┃
-10%  ┃ Уменьшить риск на сделку до 0.5%, макс. 1 позиция
      ┃
-15%  ┃ ПАУЗА 1 НЕДЕЛЯ. Пересмотр стратегии.
      ┃
-20%  ┃ СТОП. Полный аудит стратегии. Возврат на демо.
```

## Кредитное плечо

### Рекомендации по плечу

| Ситуация | Рекомендуемое плечо | Максимальное |
|----------|---------------------|-------------|
| Стандартная сделка по тренду | 3x-5x | 10x |
| Контр-трендовая сделка | 2x-3x | 5x |
| Торговля пампа (на сдутии) | 2x-3x | 5x |
| Новый листинг | 2x-3x | 5x |
| BTC/ETH | 5x-7x | 10x |
| Альткоины (волатильные) | 2x-3x | 5x |

### Связь плеча и стопа

```
ВАЖНО: Плечо НЕ влияет на риск, если стоп установлен правильно!

Пример (одинаковый риск $100):

  Без плеча:    Позиция $10,000  │  Стоп 1%   │  Убыток = $100
  Плечо 5x:    Позиция $10,000  │  Стоп 1%   │  Убыток = $100
                (маржа $2,000)   │            │

Плечо влияет на:
  ✓ Размер маржи (меньше блокируется средств)
  ✓ Риск ликвидации (чем выше плечо, тем ближе ликвидация)
  ✗ Риск в долларах (определяется стопом, не плечом)
```

### Расстояние до ликвидации

```
Формула:
  Расстояние до ликвидации ≈ (1 / Плечо) × 100%

  Плечо 3x  → Ликвидация при движении ~33% против позиции
  Плечо 5x  → Ликвидация при движении ~20% против позиции
  Плечо 10x → Ликвидация при движении ~10% против позиции
  Плечо 20x → Ликвидация при движении ~5%  против позиции

ПРАВИЛО: Расстояние от входа до стопа должно быть
         МИНИМУМ в 3 раза меньше расстояния до ликвидации.

  Пример: Плечо 5x → ликвидация ~20% → стоп максимум ~6.6%
```

## Корреляции и диверсификация

### Правило корреляции

**НЕ открывать две позиции в одном направлении на коррелированных активах!**

| Высокая корреляция (> 0.7) | Действие |
|-----------------------------|----------|
| BTC + ETH | Выбрать один |
| DOGE + SHIB | Выбрать один |
| SOL + AVAX | Выбрать один |
| Любые два топ-10 альта | Максимум один лонг + один шорт |

**Допустимые комбинации:**
- Лонг на одной монете + Шорт на другой (хедж)
- Две позиции на НЕКОРРЕЛИРОВАННЫХ активах (разные секторы)
- Одна позиция BTC/ETH + одна позиция альткоин

## Funding Rate как фильтр риска

### Таблица решений по Funding Rate

| Funding Rate | Направление | Рекомендация |
|-------------|-------------|--------------|
| > +0.05% | ЛОНГ | Осторожно — рынок перегрет в лонгах |
| > +0.05% | ШОРТ | Благоприятно — шортисты получают оплату |
| > +0.1% | ЛОНГ | **НЕ ВХОДИТЬ** — экстремальная перегретость |
| < -0.05% | ШОРТ | Осторожно — рынок перегрет в шортах |
| < -0.05% | ЛОНГ | Благоприятно — лонгисты получают оплату |
| < -0.1% | ШОРТ | **НЕ ВХОДИТЬ** — экстремальная перегретость |
| -0.01% до +0.01% | Любое | Нейтрально — нормальные условия |

## Антитилт система

### Правила после серии убытков

```
Серия убытков → Действие:

  1 убыток  → Проверить чек-лист, продолжить
  2 подряд  → Уменьшить размер позиции на 25%
  3 подряд  → ПАУЗА минимум 1 час. Анализ всех 3 сделок.
  4 за день → Уменьшить размер на 50% до конца дня
  5 за день → СТОП ТОРГОВЛИ НА ДЕНЬ

После паузы:
  → Перечитать правила стратегии
  → Проанализировать убыточные сделки в журнале
  → Первая сделка после паузы — 50% от стандартного размера
```

### Правила после серии прибылей

```
⚠️ Серия прибылей ТАКЖЕ опасна (оверконфиденс):

  5+ прибыльных подряд → Уменьшить размер на 25% (защита от overtrading)
  Дневная прибыль > 3% → СТОП ТОРГОВЛИ (зафиксировать прибыль)
```

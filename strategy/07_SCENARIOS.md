# 07 — ЧЕТЫРЕ ТОРГОВЫХ СЦЕНАРИЯ С ПРИМЕРАМИ

## Сценарий 1: Интенсивно нисходящий тренд (ШОРТ)

### Описание
Монета активно падает. Медвежий тренд подтверждён на старших ТФ. Мы строим **нисходящую наклонную сопротивления** по swing highs и входим в шорт при каждом касании.

### Визуальная схема

```
Цена ($)

$105  ★ Экстремум (Swing High #1)
       \
$103    \    ╱╲
         \  ╱  ╲
$101      \/    ★ Swing High #2 (Касание 2)
           \   │╲
$99         \  │ ╲
             \ │  ╲   ╱╲
$97           \│   ╲ ╱  ╲
               \    ★    ╲ Swing High #3 (Касание 3)
$95            |\   │╲    ╲
               │ \  │ ╲    ╲   ╱╲
$93            │  \ │  ╲    ╲ ╱  ╲
               │   \│   ╲    ★    ╲ Касание 4 ← ВХОД В ШОРТ
$91            │    \    ╲  / \    ╲
               │     \    ╲/   \    ╲
$89            │      \         \    ╲
               │       \         \    ▼ TP1
$87            │        \         \
               │         \         ▼ TP2
$85            │          \
               │           ▼ TP3
```

### Пошаговый разбор

**Шаг 1: Определение тренда (4H + 1H)**
```
Чек-лист тренда:
  ☑ EMA 9 < EMA 21 < EMA 50 на 1H
  ☑ Цена ниже EMA 200 на 4H
  ☑ Серия Lower Highs + Lower Lows на 1H
  ☑ MACD ниже нулевой линии на 1H
  → ТРЕНД: Нисходящий ✓
```

**Шаг 2: Построение наклонного уровня (15m)**
```
  1. Находим экстремум: Swing High #1 = $105
  2. Проводим линию через Swing High #2 = $101
  3. Подтверждаем: Swing High #3 коснулся линии → 3 касания ✓
  4. Проверяем наторгованность: Объём в точках касания > средний ✓
  5. Проверяем экстремум: Swing High #1 — значимый максимум ✓
```

**Шаг 3: Подготовка ко входу**
```
  Наклонная проецируется на $93.50 для Касания 4
  Зона касания (15m): $93.50 ± 0.15% = $93.36 - $93.64
  Стоп: $93.64 + 0.5 × ATR(14)

  Предположим ATR(14) = $0.80:
    Стоп = $93.64 + $0.40 = $94.04

  Размер стопа: $94.04 - $93.50 = $0.54 (0.58%)
```

**Шаг 4: Подтверждения для входа**
```
  [✓] 1. Наклонный уровень: Касание 4 нисходящей — ✓
  [✓] 2. Свечной паттерн: Падающая звезда на 5m в зоне — ✓
  [✓] 3. Объём: Объём на касании > MA(20) × 1.5 — ✓
  [✓] 4. RSI: RSI = 63 (в зоне перекупленности для нисходящего тренда) — ✓
  [ ] 5. Конфлюенция: Нет совпадения с другими уровнями — ✗

  Итого: 4 из 5 → ВХОД РАЗРЕШЁН ✓
```

**Шаг 5: Вход**
```
  Тип входа: Консервативный (market на закрытии медвежьей свечи)
  Цена входа: $93.50 (ШОРТ)
  Стоп-лосс: $94.04
  Размер стопа: $0.54

  TP1 (1R): $93.50 - $0.54 = $92.96 → Закрываем 30%
  TP2 (2R): $93.50 - $1.08 = $92.42 → Закрываем 40%
  TP3 (3R): $93.50 - $1.62 = $91.88 → Закрываем 30%

  Депозит: $10,000
  Риск 1% = $100
  Размер позиции: $100 / 0.0058 = $17,241
  Плечо 5x → Маржа: $3,448
```

## Сценарий 2: Интенсивно восходящий тренд (ЛОНГ)

### Описание
Монета активно растёт. Бычий тренд подтверждён. Строим **восходящую наклонную поддержки** по swing lows и входим в лонг при каждом касании.

### Визуальная схема

```
Цена ($)

                                               ▲ TP3
                                              /
                                    ▲ TP2    /
                                   /        /
                         ▲ TP1    /        /
                        /        /        /
$115           ★ Касание 4      /        /
              / \    ← ВХОД В ЛОНГ      /
$113         /   \     /              /
            /     \   /              /
$111       /       \ /              /
          /     ★ Swing Low #3 (Касание 3)
$109     /     / \             /
        /     /   \           /
$107   /     /     \         /
      /     /       ★ Swing Low #2 (Касание 2)
$105 /     /       / \
    /     /       /   \
$103     /       /     \
        /       /       \
$101 ★ Экстремум (Swing Low #1)
```

### Пошаговый разбор

**Шаг 1: Определение тренда (4H + 1H)**
```
Чек-лист тренда:
  ☑ EMA 9 > EMA 21 > EMA 50 на 1H
  ☑ Цена выше EMA 200 на 4H
  ☑ Серия Higher Highs + Higher Lows на 1H
  ☑ MACD выше нулевой линии на 1H
  → ТРЕНД: Восходящий ✓
```

**Шаг 2: Построение наклонного уровня (15m)**
```
  1. Находим экстремум: Swing Low #1 = $101
  2. Проводим линию через Swing Low #2 = $107
  3. Подтверждаем: Swing Low #3 коснулся линии → 3 касания ✓
  4. Проверяем наторгованность ✓
  5. Проверяем экстремум ✓
```

**Шаг 3: Подготовка ко входу**
```
  Наклонная проецируется на $115.00 для Касания 4
  Зона касания: $114.83 - $115.17
  ATR(14) = $0.90:
    Стоп = $114.83 - $0.45 = $114.38
  Размер стопа: $115.00 - $114.38 = $0.62 (0.54%)
```

**Шаг 4: Подтверждения**
```
  [✓] 1. Наклонный уровень: Касание 4 восходящей — ✓
  [✓] 2. Свечной паттерн: Бычье поглощение на 5m — ✓
  [✓] 3. Объём: Повышенный на касании — ✓
  [✓] 4. RSI: RSI = 42 (перепроданность для бычьего тренда) — ✓
  [✓] 5. Конфлюенция: Совпадение с EMA 50 — ✓

  Итого: 5 из 5 → ИДЕАЛЬНЫЙ ВХОД ✓✓✓
```

**Шаг 5: Вход**
```
  Тип входа: Агрессивный (limit) — 5 из 5 подтверждений!
  Цена входа: $115.00 (ЛОНГ)
  Стоп-лосс: $114.38
  TP1 (1R): $115.62 → 30%
  TP2 (2R): $116.24 → 40%
  TP3 (3R): $116.86 → 30%
```

## Сценарий 3: Памп — торговля на сдутии

### Описание
Монета совершила резкий вылет вверх (памп). Образовались **имбалансные зоны (FVG)**. Мы ждём завершения импульса и входим **на сдутии** — при откате к имбалансным зонам.

### Визуальная схема

```
Цена ($)

$150  │  ╱╲ ← ВЕРШИНА ПАМПА
      │ ╱  ╲     RSI > 85
      │╱    ╲    Объём: 500% от среднего
$145  │      ╲
      │       ╲
$140 ═╪═══════╲══════════ FVG #1 (Imbalance Zone)
      │        ╲          ← ЗОНА ВХОДА В ШОРТ
$137 ═╪════════╲═════════
      │         ╲
$135  │          ╲  ╱─── Отскок и повторное падение
      │           ╲╱
$132 ═╪════════════╲════ FVG #2 (Imbalance Zone)
      │             ╲    ← АЛЬТЕРНАТИВНАЯ ЗОНА ВХОДА
$130 ═╪══════════════╲══
      │               ╲
$128  │                ╲
      │                 ╲
$125  │──────────────────╲── Цена ДО пампа
      │                   │
      │    ПАМП →  │← СДУТИЕ →
      │            │
      ────────────────────────── Время
```

### Определение имбалансных зон (FVG)

```
Fair Value Gap (FVG) — три свечи:

Бычий FVG (для шорта на сдутии):

    ┃         ← Свеча 3: Low выше High свечи 1
    ┃
    ┃
  ─ ┤ ─ ─ ─ ─ Low свечи 3
    │
  █████████   ← ЭТО FVG (имбалансная зона)
  █████████      Нет перекрытия тел свечей 1 и 3
    │
  ─ ┤ ─ ─ ─ ─ High свечи 1
    ┃
    ┃         ← Свеча 1: High ниже Low свечи 3
    ┃
    ┃
  [Св.1]  [Св.2]  [Св.3]

  FVG = Зона между High свечи 1 и Low свечи 3
  Цена стремится ВЕРНУТЬСЯ и "заполнить" этот гэп
```

### Пошаговый разбор торговли пампа

**Шаг 1: Идентификация пампа**
```
  ☑ Движение > 10% за 1-4 часа
  ☑ Объём > 300% от среднего 24ч
  ☑ Множественные FVG на графике (минимум 2)
  ☑ RSI > 85 на 15m (экстремальная перекупленность)
  ☑ OI вырос > 20% за время пампа
  → ПАМП ПОДТВЕРЖДЁН ✓
```

**Шаг 2: Ожидание сдутия**
```
  НЕ ВХОДИМ на вершине!

  Ждём:
  ☑ Первый откат > 3% от вершины
  ☑ RSI опустился ниже 70
  ☑ Объём снизился от пиковых значений
  ☑ Формирование первых swing highs после вершины
  → СДУТИЕ НАЧАЛОСЬ ✓
```

**Шаг 3: Построение наклонного уровня по откатам**
```
  После вершины пампа цена формирует нисходящие swing highs.
  Строим нисходящую наклонную сопротивления:

  $150 ★ Вершина пампа (Экстремум)
        \
  $147   ★ Swing High #2 (первый откат)
          \
  $145     ★ Swing High #3 (второй откат)
            \
  $143.5     ★ Касание 4 → ВХОД В ШОРТ
              \
```

**Шаг 4: Вход (с усиленной фильтрацией)**
```
  [✓] 1. Наклонный уровень после пампа: 3+ касания — ✓
  [✓] 2. Свечной паттерн: Медвежье поглощение — ✓
  [✓] 3. Объём: Снижение объёма на подъёмах — ✓
  [✓] 4. RSI: Дивергенция (цена ниже, RSI выше) — ✓
  [✓] 5. FVG: Незаполненные имбалансы ниже — ✓

  ВХОД: Шорт $143.50
  Стоп: $145.00 (за наклонной)
  TP1: Верхняя граница FVG #1 ($140)
  TP2: Середина FVG #1 ($138.50)
  TP3: Нижняя граница FVG #2 ($130) или цена до пампа ($125)
```

**Шаг 5: Альтернативный ЛОНГ (на заполнении FVG)**
```
  Если памп был на реальных новостях (не манипуляция),
  можно торговать ЛОНГ от нижней FVG:

  ВХОД: Лонг $132 (нижняя граница FVG #2)
  Стоп: $130 (под FVG)
  TP1: $135
  TP2: $140 (FVG #1)
  TP3: Ретест вершины $150

  ⚠️ ТОЛЬКО если есть фундаментальные причины для роста!
```

## Сценарий 4: Недавние листинги (до 2 месяцев)

### Описание
Монета была листингована не более 60 дней назад. Исторических данных мало, но первые наклонные уровни уже формируются. Торгуем **первое направленное движение**.

### Визуальная схема

```
Цена ($)

         │  Листинг → Первые дни → Формирование структуры
         │
$12      │          ╱╲
         │         ╱  ╲      ╱╲
$11      │        ╱    ╲    ╱  ╲
         │  ╱╲   ╱      ╲  ╱    ╲
$10      │ ╱  ╲ ╱        ╲╱      ╲
         │╱    ★           ★       ★ Swing Low #3
$9       │     │           │       │
         │     Swing       Swing   │
$8       │     Low #1     Low #2   │
         │                         │← 3 касания!
         │                         │
         │  ← Наклонная поддержка формируется →
         │
         ────────────────────────────── Время
         День 1    День 15   День 30   День 45
```

### Особенности торговли новых листингов

**Отличия от стандартных сценариев:**

| Параметр | Стандарт | Новый листинг |
|----------|----------|---------------|
| Мин. касаний | 3 | 3 (можно начинать быстрее) |
| Контекст старших ТФ | Обязателен | Не требуется (нет истории) |
| Размер позиции | 100% | 75% (повышенная неопределённость) |
| Плечо | До 10x | До 5x максимум |
| R:R минимум | 2:1 | 2.5:1 (компенсация неопределённости) |
| Объём 24ч | > $20M | > $20M (обязательно!) |

### Пошаговый разбор

**Шаг 1: Скрининг нового листинга**
```
  ☑ Дата листинга: менее 60 дней назад
  ☑ Объём 24ч > $20M
  ☑ Доступны фьючерсы (USDT-M Perp)
  ☑ Спред < 0.05%
  ☑ Прошла хотя бы 1 неделя с листинга (формирование структуры)
  → МОНЕТА ПОДХОДИТ ✓
```

**Шаг 2: Анализ первичной структуры**
```
  Без контекста старших ТФ! Работаем с тем, что есть:

  1. Определяем диапазон торговли первых дней
  2. Ищем формирующиеся swing highs / swing lows
  3. Строим первую наклонную при 3 касаниях
  4. Определяем направление первого тренда
```

**Шаг 3: Построение и вход**
```
  Первая восходящая наклонная сформирована (3 swing lows):

  $10.00 → $10.50 → $11.00 (восходящие минимумы)

  Наклонная поддержка проецируется на $11.50 для 4-го касания

  ВХОД: Лонг $11.50 от наклонной поддержки
  Стоп: $11.20 (под наклонной + буфер)
  TP1: $12.00
  TP2: $12.50
  TP3: $13.00

  Размер позиции: 75% от стандарта
  Плечо: 3x-5x
```

**Шаг 4: Управление позицией**
```
  Новые листинги более волатильны!

  ⚠️ Дополнительные правила:
  - Трейлинг-стоп активнее (каждые 3 свечи, не 5)
  - При объёме < 50% от среднего → закрываем позицию
  - При появлении крупных новостей о монете → закрываем
  - Временной стоп: 15 свечей вместо 20 (ускоренная ротация)
```
